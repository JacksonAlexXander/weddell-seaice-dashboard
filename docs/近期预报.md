# 威德尔海近期预报

NSIDC-0116 训练归档截止 2025-12-30。模型以漂移观测滑窗为输入，输入一个未来日期本身无法替代观测。近期预报使用独立的 EUMETSAT OSI SAF 缓存，以最后一份实际观测的结束时间起报。归档回测仍使用原数据和已公布的历史测试口径。

## 近期观测

使用 MET Norway 官方目录中的 OSI-405-d 南半球多卫星融合产品。每日发布一份覆盖过去约 48 小时的漂移估计，原生采样间距 62.5 km。选择最近连续 10 份文件。利用起点和终点的经纬度及观测时间差计算 EPSG:3409 投影分量，转换为 cm/s 后映射到训练网格。沿用质量掩膜和训练数据覆盖区域，缺测保持掩膜。映射后的网格间距约 25 km，观测信息的原始空间采样仍为 62.5 km。

数据为 EUMETSAT OSI SAF 的 Global Low Resolution Sea Ice Drift（2025），OSI-405-d，CC BY 4.0。MET Norway 提供文件分发。本项目进行了筛选、投影转换及重采样。[产品与许可](https://osi-saf.eumetsat.int/products/osi-405-d) · [数据 DOI](https://doi.org/10.15770/EUM_SAF_OSI_NRT_2007)

## 预报时效

- SimVP 输入 10 帧并直接输出已训练模型的前 1–3 个日时效。Ridge 和 Random Forest 使用最近 8 帧，第 2–3 天将此前的预测送入下一次推理。
- 轨迹每一天按当天预测场积分，在次日开始时重新按位置取速度。下一日缺少覆盖时，轨迹提前结束。表格和区域图的各日 u/v 对应固定像元，轨迹对应移动位置。
- 起报时刻和预报截止以 UTC 标明。缓存、数据发布延迟或所选时效可能使结果全部落在当前时刻以前。界面按实际时间提示。
- 近期输入是 48 小时平均漂移，与 NSIDC 训练分布存在差异。多日输出为试验性预报，历史 NSIDC RMSE 不能代表近期预报精度。

## FastAPI

`GET /api/recent` 返回近期批次及推荐像元。 `POST /api/recent/refresh` 从官方目录更新观测，成功后原子替换本地缓存。 `GET /api/recent/field` 返回当前观测场，提供 `model` 和 `lead_days` 时返回该时效的预测场。

```json
{
  "source": "recent",
  "date": "latest",
  "model": "simvp",
  "cell": {"row": 65, "col": 60},
  "lead_days": 3
}
```

向 `POST /api/predict` 提交上面的 JSON。`data_time.observation_end_at` 和 `forecast_valid_until` 为 UTC 时间戳。 `daily_forecasts` 返回所选像元的每日日均 u/v，`series_horizon` 返回逐时位置。 `series_24h` 保留第一天结果，以兼容旧客户端。归档模式继续支持原请求格式。
