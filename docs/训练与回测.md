# 威德尔海海冰漂移训练与回测

从 Newsmy 的 `NSIDC0116_Weddell_SeaIce_Motion_Dataset` 读取 48 个年度 NetCDF，逐年校验大屏训练缓存的时间轴、网格、经纬度、有效掩膜和全部有效 `u/v` 矢量。数据覆盖 1978-10-25 至 2025-12-30，共 17,188 个有效日，威德尔海子集为 116 × 158 个像元。详见 [逐年核验记录](newsmy-data-verification.json) 和 [NSIDC-0116 v4 产品页](https://nsidc.org/data/nsidc-0116/versions/4)。

## 模型与论文

沿用现有 SimVP 风格的时空网络和权重。网络用空间门控建模相邻像元，用时间混合建模连续漂移，并保留原模型的年内周期通道。输入为 10 日场和季节特征，模型输出五个日尺度漂移场，大屏使用第 1 日的 `u/v`。保留 Ridge、Random Forest 和两个基线，便于按统一口径比较。

- CVPR 2025 的 IceDiff 在规则极区网格上预测海冰浓度。它提供了保留原生网格空间结构的任务参考，本项目的训练目标是南极海冰漂移矢量。[IceDiff](https://openaccess.thecvf.com/content/CVPR2025/html/Xu_IceDiff_High_Resolution_and_High-Quality_Arctic_Sea_Ice_Forecasting_with_CVPR_2025_paper.html)
- NeurIPS 2025 的 ST-SSDL 强调时间序列对历史模式的偏离。本项目把这个思路用于监督损失，用起报日至次日的实测矢量变化给次日误差加权，掩去任一日缺测的像元。[ST-SSDL](https://proceedings.neurips.cc/paper_files/paper/2025/hash/d7b351608d824a4680344a02b180a947-Abstract-Conference.html)
- ICML 2026 的 Residual-Guided Multi-Resolution Refinement 展示了基于残差改进已有区域气候模型的研究路线。本项目沿用已有海冰模型做 24 小时目标微调，保留原分辨率。[ICML 2026 论文](https://proceedings.mlr.press/v306/gao26p.html)

上述三个会议均在 CCF 人工智能 A 类目录内。[CCF 官方目录](https://www.ccf.org.cn/Academic_Evaluation/AI/)

## 实际训练

从原 SimVP 第 23 轮权重初始化，先试跑只更新预测头的方案，再以 Apple MPS 完成全网微调 3 轮。以 1978–2017 年为训练段，在连续日窗口中每 12 个可用起点取一个，共 1,174 个训练窗。2018–2021 年保留 96 个均匀抽取的验证窗，窗口包含的日期全部留在本分段。2022–2025 年用于独立测试。验证按次日矢量 RMSE 选权重，最优为微调第 2 轮。

- 验证集按批聚合的次日矢量 RMSE 从 **9.4148** 降至 **9.3503 cm/s**。
- 原权重与新权重分别位于 `models/simvp-v1/ckpt_best.pt` 和 `models/simvp-24h/ckpt_best.pt`。
- 批量回测的预测场由选定权重离线生成。FastAPI 单点请求首次运行模型前向推理，同模型、日期、像元的重复请求可复用内存结果。

## 独立测试

同一组 277 个连续日窗口，覆盖 1,509,249 个有效像元样本。所有行的误差按有效样本池化。技能分为 1 − 模型 RMSE / 持续性 RMSE，越高越好。

| 模型 | 24h 矢量 RMSE（cm/s） | 矢量 MAE（cm/s） | 技能分 |
| --- | ---: | ---: | ---: |
| SimVP 24h 微调 | **10.4485** | **8.6291** | **20.54%** |
| 原 SimVP | 10.5530 | 8.7284 | 19.74% |
| Random Forest | 11.1019 | 9.1742 | 15.57% |
| Ridge | 11.2330 | 9.2986 | 14.57% |
| 气候态 | 12.9504 | 10.6206 | 1.51% |
| 持续性 | 13.1486 | 10.9619 | 0.00% |

原 SimVP 和新 SimVP 均重新推理，Ridge、Random Forest 与基线复用原权重对同一组像元的已存预测。完整数据见 [SimVP 评估 JSON](../data/processed/dashboard/metrics_simvp.json) 与 [大屏评估 JSON](../data/processed/dashboard/metrics.json)。历史回测显示真实日漂移值，缺测像元留空并跳过误差计算。产品的原生时间分辨率为一天，逐时轨迹是在 EPSG:3409 中对预测日矢量做匀速积分。最后观测日可用于起报，目标日缺少观测时大屏会明确标注。

## 复现微调

在项目根目录、已安装 `requirements.txt` 的 Python 环境中运行：

```bash
python src/train.py --tag simvp-day1-tuned \
  --init-weights models/simvp-v1/ckpt_best.pt --strict-daily \
  --day1-weight 0.5 --selection-windows 96 --epochs 3 \
  --batch 2 --stride 12 --lr 0.0001 --lr-min 0.000015 --device auto

python src/serving/build_simvp_artifacts.py \
  --ckpt models/simvp-day1-tuned/ckpt_best.pt \
  --compare-ckpt models/simvp-v1/ckpt_best.pt \
  --eval --precompute --update-combined --out-dir reports/simvp-day1-tuned
```
